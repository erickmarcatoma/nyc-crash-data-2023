# NYC Crash Data Visualization (2023)

An interactive web application visualizing contributing factors in 2023 NYC motor vehicle collisions, highlighting the prevalence of driver inattention and distraction.

## Features
- Key metric cards summarizing top collision categories.
- Interactive horizontal bar chart built with Chart.js.
- Modular Flask backend API ready for deployment.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, Chart.js
- **Backend:** Python, Flask, Flask-CORS
- **Deployment:** Configured for Vercel
